# 🛡️ Ethical Hacking Project: Webpage Vulnerability Testing

This project focuses on identifying and mitigating security vulnerabilities in web applications using ethical hacking techniques. It includes both **manual and automated penetration testing** with industry-standard tools like **OWASP ZAP**, **Nmap**, and **Burp Suite**.

---

## 📌 Objectives

- Identify common web vulnerabilities such as:
  - ✅ SQL Injection (SQLi)
  - ✅ Cross-Site Scripting (XSS)
  - ✅ Cross-Site Request Forgery (CSRF)
- Perform port scanning and service enumeration.
- Generate security reports with risk mitigation strategies.
- Ensure testing complies with ethical and legal standards.

---

## 🔧 Tech Stack & Tools

- **Operating System:** Linux (Ubuntu/Kali)
- **Scripting:** Bash
- **Tools Used:**
  - [OWASP ZAP](https://www.zaproxy.org/)
  - [Burp Suite](https://portswigger.net/burp)
  - [Nmap](https://nmap.org/)
  - Linux Security Utilities (`ping`, `netcat`, etc.)
